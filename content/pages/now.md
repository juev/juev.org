Это [now-страница](https://nownownow.com/about): чем я занимаюсь в последнее время.

- [post](https://github.com/juev/post) — публикация одного сообщения сразу в несколько аккаунтов Bluesky и Mastodon: Markdown, автоматические треды, подгонка медиа и отправка по расписанию. Пока выходят только release candidate.
- [teleport](/2026/11/13/teleport/) — иконка-кнопка на Android: нажатие открывает выбранное приложение или ссылку, долгое нажатие — меню с остальными действиями. [Репозиторий](https://github.com/juev/teleport).
- [hermes](/2026/10/28/hermes-android/) — клиент для Android к агенту Hermes вместо Telegram и Matrix: отдельный чат на каждую задачу, поиск по всем разговорам, управление сервером и встроенный Tailscale. Для macOS есть [hermes-macos](https://github.com/juev/hermes-macos) — нативный клиент на SwiftUI к тому же дашборду, без Electron и веб-вью. У Android-версии пока только release candidate, у macOS вышел 0.1.4. [Репозиторий](https://github.com/juev/hermes).
- [memcue](/2026/10/27/memcue/) — долговременная память для Claude Code и Hermes: факты лежат в SQLite и подтягиваются по словам перед каждым запросом. [Репозиторий](https://github.com/juev/memcue).
- [notes](https://github.com/juev/notes) — local-first заметки для macOS и Android с общим ядром на Rust и синхронизацией через WebDAV или обычный каталог. Релизов пока нет.
- [go-cache-lru](/2026/10/27/go-cache-lru/) — демон GOCACHEPROG, который держит кеш сборки Go в заданном размере и вытесняет записи по LRU; локальный диск и, по желанию, S3 или R2. [Репозиторий](https://github.com/juev/go-cache-lru).
- [freshgo](/2026/10/10/freshgo/) — сервер лент на Go, совместимый с FreshRSS. К нему [brook](https://github.com/juev/brook), читалка для Android, которая работает с freshgo и другими серверами с Google Reader API.
- [lists](/2026/10/11/lists/) — local-first список дел для macOS и Android с веб-интерфейсом на своём сервере и синхронизацией через WebDAV или CalDAV.
- [linkding на Go](/2026/10/02/linkding-go/) — независимый порт linkding с SQLite и PostgreSQL. К нему [shareding](/2026/09/29/shareding-android/): отправляет ссылки в linkding с Android и держит очередь, пока сервер недоступен.
- [nebula-mesh](https://github.com/forgekeep/nebula-mesh) — self-hosted control plane для mesh VPN Nebula: сертификаты, хосты и конфигурация из одного места. Пост: [23 уязвимости за четыре с половиной месяца](/2026/10/01/nebula-mesh-advisories/).
- [hledger-lsp](https://github.com/juev/hledger-lsp) и [hledger-vscode](https://github.com/juev/hledger-vscode) — language server и расширение VS Code для журналов hledger.
- [perigee](https://github.com/juev/perigee) — читалка электронных книг для Android на движке crengine с синхронизацией через bookOrbit.
- Каждую неделю собираю [«Ссылки»](/tags/links/) — подборку того, что прочитал.
